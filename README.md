# buddy — 会成长的个人助手

实验项目：实现一个持续为我工作的个人助手，具备五项基础能力。

| 能力 | 说明 |
|---|---|
| 1. 个人数据库 | 索引、检索我的资料，随资料变化更新索引，回答时定位原文（Markdown + 目录结构） |
| 2. 持续关联 smail 邮箱 | 获取新邮件、关联历史往来，结合个人资料拟回复草稿；发送前必须经我确认；同一封邮件不重复处理 |
| 3. 办理 ehall 事务 | 在 ehall.nju.edu.cn 查询信息、完成至少一种事务的材料准备与表单填写；提交前展示关键字段及后果，由我明确确认 |
| 4. 手机端联动 | 从手机发起任务、查看进度、编辑草稿、确认操作；不依赖桌面端常开的对话窗口 |
| 5. 能力组合 | 五项能力共享上下文，至少跑通一条我愿意反复使用的完整流程 |

## 工作方式

- 成功流程和用户纠正保存为**可阅读、可修改**的脚本、技能或记忆，用 Git 管理。
- 示例：用户指出"不要把报名截止时间当成活动开始时间"，这条规则要能在**新会话**中用于另一份通知。
- 行为保守：涉及提交、发送、退课、撤销申请等外部操作，一律先展示后果、等用户确认，绝不自行决定。

## 仓库结构（随开发演进）

```
buddy/
├── AGENTS.md      # 助手的工作规则（每次会话先读）
├── README.md      # 本文件
├── memory/        # 个人资料与长期记忆（Markdown）
├── skills/        # 可复用流程脚本/技能
└── drafts/        # 邮件草稿、表单等待确认产物
```
